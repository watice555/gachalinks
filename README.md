# Gacha Links

面向原神、崩坏：星穹铁道、绝区零、鸣潮与异环玩家的精选资料站、数据工具与创作工具导航。

## 本地开发

```bash
npm install
npm run dev
```

## GitHub Pages

项目已配置 GitHub Actions。推送到 `main` 分支后，工作流会构建静态站点并发布至 GitHub Pages。

首次发布时，请在仓库的 **Settings → Pages → Build and deployment** 中将 Source 设为 **GitHub Actions**。

构建配置会自动识别：

- `username.github.io` 用户主页仓库部署在根路径；
- 普通项目仓库部署在 `username.github.io/repository-name/` 子路径。
